# EzFPS: tên hiển thị và logo — Kế hoạch triển khai

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tên hiển thị "EzFPS" và logo "Màn hình 60" nhúng trong exe, dùng cho cả khay và cửa sổ; phiên bản 1.5.0.

**Architecture:** Một script tái tạo được (`scripts/make-icon.ps1`, dùng System.Drawing) vẽ `src/FpsOverlay/Assets/EzFPS.ico` 7 cỡ. csproj nhúng nó qua `ApplicationIcon` và làm tài nguyên. Khay và cửa sổ nạp icon từ tài nguyên. Chuỗi hiển thị "FPS Overlay" đổi thành "EzFPS"; tên kỹ thuật giữ nguyên.

**Tech Stack:** C# / .NET 10, WPF, WinForms NotifyIcon, PowerShell 5.1 + System.Drawing, xUnit.

**Spec:** `docs/superpowers/specs/2026-11-05-ezfps-branding-design.md`

## Global Constraints
- **Logo:** màn hình nền `#140620`, viền `#FF4FD8` bo góc, chân đế `#FF4FD8`, số "60" trắng đậm font đơn cách (Consolas hoặc JetBrains Mono nhúng). Hình học theo viewBox 64×64 của bản vẽ thử:
  - khung: rect x4 y8 w56 h40 rx5, viền 3.5;
  - cổ: rect x24 y50 w16 h4;
  - đế: rect x16 y55 w32 h4 rx2;
  - chữ "60": cỡ 22, tâm x32, đường chân chữ y38.
- **Cỡ ico:** 16, 24, 32, 48, 64, 128, 256. Bản 256 lưu dạng PNG trong ico.
- **Bản 16 px (và 24 px):** bỏ chân đế, khung chiếm gần hết ô, viền dày ~2 px, số "60" to nhất còn vừa.
- **Tên hiển thị "EzFPS"** ở: lối tắt `EzFPS.lnk` (mô tả "EzFPS"), `DisplayName`/`Publisher` "EzFPS", mọi chuỗi giao diện/tiêu đề/thông báo, README (tiêu đề, mô tả), tiêu đề release trong `release.ps1` ("EzFPS <version>").
- **Giữ nguyên:**
  - `FpsOverlay.exe`; kho `ckhangg/FpsOverlay`; URL API;
  - thư mục `Program Files\FpsOverlay`, `%AppData%\FpsOverlay`, `Documents\FpsOverlay\Logs`;
  - tên tác vụ, khoá Uninstall `FpsOverlay`, tên mutex, namespace, tên dự án.
- **Lối tắt cũ:** khi cài, cập nhật hoặc gỡ, xoá `FPS Overlay.lnk` cũ trong Start Menu chung nếu có.
- **Phiên bản:** `1.5.0`.
- Build 0 cảnh báo, mọi test qua.
